# Which image API can draw a Seat's Mask — one small square icon from a one-line Give, in house style, in a few seconds, twenty times a night?

Researched 2026-09-09 for the [design brief](../design-brief.md). Question: at the start of every Page each Seat submits a one-line Give ("Liminal spaces", "Vecna and Stranger Things", "can of worms", "murder"). We want one small square **Mask** per Seat per Page — 256–512 px is plenty, icon-like, legible at chip size across a table, and all twenty of a night's images in one house style so they read as a set. It should land inside the wait screen before the Page is written, so a few seconds is the budget. The server is Elixir/Phoenix on a DigitalOcean VPS in New York and can call any HTTP API; the client is a laptop Stage plus Android/iOS phones. Which image API actually fits, and what does a night cost?

Method: every claim traces to a primary source — vendor API references, model cards, pricing pages, first-party docs, and the Azure retail-prices API — all fetched 2026-09-09. Two vendor sites (Stability AI's developer platform, Reve's API console) render entirely client-side and returned an empty shell to every fetch attempt, including plain `curl`; those cells say so rather than guessing. Where a vendor page does not state a figure the cell says **not found**. Nothing is estimated except the explicitly *computed* cost-per-night column, which is arithmetic on cited prices. The artificialanalysis.ai leaderboard appears once, in §7, clearly labelled secondary. No vendor is recommended; §9 states implications only.

Working assumptions used only for arithmetic: **20 images a night** (2 Seats × 10 Pages), at the **smallest square size at or above 256 px that the vendor offers**. Where a vendor bills per megapixel, a 1024×1024 image is taken as 1.05 MP and priced at 1 MP unless the vendor states rounding.

Excluded per repo policy (`~/.claude/.../no-inference-spend-to-china.md`): first-party Alibaba/Qwen, MiniMax, Zhipu, Moonshot and ByteDance/Seedream APIs. US-hosted open weights of any origin are in scope.

## 8. Flagged inconsistencies

- **OpenAI publishes per-image prices on one model page and nowhere else.** `gpt-image-1-mini` carries "$0.005–$0.006 per image" style tiers ([mini](https://developers.openai.com/api/docs/models/gpt-image-1-mini)), while the `gpt-image-2` and `gpt-image-2.5-flare` pages carry none and the pricing page says to "use the calculator in the image generation guide" ([pricing](https://developers.openai.com/api/docs/pricing)) — and the guide, as fetched, contains no cost section at all ([guide](https://developers.openai.com/api/docs/guides/image-generation)). Tokens-per-image is not published anywhere primary, so a GPT Image 2 Mask cannot be costed from OpenAI's own documents.
- **OpenAI's `size` enum still advertises `256x256` and `512x512`**, but the same reference restricts custom GPT-model sizes to "total pixels between 655,360 and 8,294,400" ([create](https://developers.openai.com/api/docs/api-reference/images/create)), which excludes both. The small sizes are DALL·E legacy.
- **Latency is documented by the host, not the author.** OpenAI states no figure; Microsoft, reselling the same models, states "10-30 seconds" ([Azure how-to](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/how-to/dall-e)).
- **MAI-Image-2.6 is deployable but not yet priced.** The Foundry how-to lists 2.6 and 2.6-Flash as deployable ([how-to](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-mai-image)), yet the Azure retail-prices API returns meters only up to "Image 2.5 Pro" ([retail prices](https://prices.azure.com/api/retail/prices?$filter=productName%20eq%20%27MAI%20Models%27)). Microsoft's own MAI model card is dated 4 September 2026, five days before this research.
- **Google's docs and pricing disagree about what 0.5K means.** The docs attribute "512px (0.5K)" to Gemini 3.1 Flash Image and say Lite "supports only 1K" ([image generation](https://ai.google.dev/gemini-api/docs/image-generation)), yet the cheaper Lite model is the one you would reach for at icon size — and Lite's 1K price ("$0.0336") undercuts Flash's 0.5K price ("$0.045") ([pricing](https://ai.google.dev/gemini-api/docs/pricing)). Paying more for fewer pixels is a real outcome here.
- **Imagen's shutdown date has passed** while its documentation page is still live ([Imagen](https://ai.google.dev/gemini-api/docs/imagen)).
- **BFL's docs live on two hosts.** `docs.bfl.ai` serves an introduction that names "FLUX 3" and points at `https://docs.bfl.ml/llms.txt` for everything else; the pricing and API reference are only on the `.ml` host ([pricing](https://docs.bfl.ml/quick_start/pricing.md)).
- **Ideogram's and Leonardo's prices are unfetchable by design.** Both put the numbers behind client-rendered pages or in-app calculators ([Ideogram setup](https://developer.ideogram.ai/ideogram-api/api-setup.md), [Leonardo calculator](https://docs.leonardo.ai/docs/plan-with-the-pricing-calculator)); the only fetchable Ideogram per-image figures are a reseller's ([Replicate](https://replicate.com/ideogram-ai/ideogram-v3-turbo)).
- **Recraft's icon styles are on its oldest model.** The eleven named icon styles belong to Recraft V2 vector, not V3, V4 or V4.1 ([styles](https://www.recraft.ai/docs/api-reference/styles.md)) — the icon vocabulary and the newest quality are not the same product.
- **fal quotes a per-megapixel rate that cannot be undercut.** "$0.003 per megapixel" with "images billed by rounding up to the nearest megapixel" ([schnell](https://fal.ai/models/fal-ai/flux/schnell)) means a 512² Mask costs exactly what a 1024² Mask costs.

## 9. Implications for our design

- **A whole night of Masks is cheap everywhere, and the spread between the cheapest and dearest credible option is roughly seventy-fold, not seven-hundred-fold.** $0.054 (Together FLUX.1 schnell) to $0.10 (gpt-image-1-mini low) to $0.90 (Nano Banana 2 at 0.5K) to $4.22 (GPT Image 2 high, at the secondary price) per night. At 20 images a night, price does not decide this; it decides whether regenerating a Mask on demand is free or a thing to think about.
- **The thing nobody will promise is the thing we actually need.** Only Microsoft publishes a latency figure at all — "10-30 seconds" for OpenAI's image family — and that is *above*, not below, our few-second wait-screen budget. Every other vendor publishes nothing. The fast levers that exist are named rather than measured: `quality: low`, `rendering_speed: TURBO`, `thinking_level: minimal`, FLUX.1 schnell's "1 to 4 steps", the Lite and Flash variants. A measured bake-off from the New York VPS is the only way to know, and the Mask design should assume a placeholder chip that gets replaced when the image lands.
- **"Twenty images that read as a set" splits the field cleanly.** Ideogram (`style_codes`, `style_reference_images`, `style_type`, `seed`) and Recraft (`style_id` built once from up to ten reference images, plus a named icon vocabulary) are built for exactly this; BFL and the open-weight hosts give a seed and reference images; Nano Banana gives references but no seed; **MAI-Image-2.6 gives neither — its generations endpoint takes only prompt and dimensions** — and OpenAI's GPT image models give no seed and no style preset. On a house-style requirement, the newest and highest-Elo models are the weakest tools.
- **A dark Give is a moderation question with only two tunable answers.** "murder" and "Vecna" are ordinary horror-adjacent vocabulary, and only OpenAI (`moderation: "low"`), BFL (`safety_tolerance` 0–5) and the open-weight hosts (`enable_safety_checker`, though "Disabling it requires account authorization") expose a dial. Google, Microsoft and Meta apply fixed system-level filtering. Whatever we pick, a refusal is a state the Page must survive — a Seat whose Give is rejected still needs a chip.
- **Rate limits, not price, are what could actually break a night.** MAI-Image-2.6 allows 2–12 requests per minute; OpenAI Tier 1 allows 5 images per minute. Two Seats submitting simultaneously at the top of every Page is a burst pattern, and a Page opening at 5 IPM is fine while a Page opening at 2 RPM is not.
- **Delivery shape has a real cost on our stack.** Base64-in-JSON (OpenAI, Gemini, MAI, Muse) means the Phoenix server holds the bytes and can persist them immediately; URL-based delivery (BFL, Ideogram, fal, Replicate) means a second fetch, and BFL's "Generated images expire after 10 minutes" plus Ideogram's expiring links make "download and re-serve" mandatory rather than optional if a Mask is ever shown again after the Page.
- **Two candidates cannot be evaluated on the record.** Stability AI and Reve publish nothing fetchable; Leonardo publishes no rate at all. Choosing any of the three means accepting facts we cannot cite today.
